## 1. Executive Summary & Brand Positioning

**NIFT Hyderabad Thrift Closet** is a circular peer-to-peer fashion platform designed exclusively for the **NIFT Hyderabad campus (Madhapur)**. It bridges the gap between students' rapid wardrobe turnover (seasonal collections, studio assignments, styling shoots) and conscious consumption.

Instead of operating as a faceless commercial classifieds site or relying on unreliable Instagram story drops, the platform anchors second-hand fashion in **editorial wardrobe curation**, **transparent flat-lay sizing**, and **physical campus community drops**.

## 2. The Bifurcated Condition & Pricing Paradigm

The platform divides the 5-tier condition rubric into two distinct commercial postures:

```
┌────────────────────────────────────────────────────────────────────────┐
│ TRACK A: DIRECT FIXED PRICE (Tiers 1, 2, 3)                            │
├────────────────────────────────────────────────────────────────────────┤
│ • 1. New / Unworn (Deadstock, tags attached)                           │
│ • 2. Like New (Worn 1-2 times, pristine)                               │
│ • 3. Gently Used (Light normal wear, structurally sound)               │
│                                                                        │
│ UX Rule: ZERO BIDDING / ZERO HAGGLING.                                 │
│ Sellers set a firm, fair price. Buyers purchase directly or swap.      │
│ Protects sellers from lowball DMs and preserves garment dignity.       │
└────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────┐
│ TRACK B: CAMPUS LIVE BIDDING (Tiers 4, 5)                              │
├────────────────────────────────────────────────────────────────────────┤
│ • 4. Well Used (Softened, vintage patina, wash fade)                   │
│ • 5. Visible Wear / Flaws (Distressed, frayed, flaws disclosed)        │
│                                                                        │
│ UX Rule: AUCTION / LIVE BIDDING ENGINE.                                │
│ Seller introduces a Base Starting Bid (e.g. ₹300). Students place live │
│ increment bids (+₹50, +₹100). The auction closes prior to the Friday   │
│ campus break drop, unlocking pieces for budget thrifters & upcyclers.  │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. The Campus Drop Event Model (Zero Shipping Waste)

Rather than introducing courier partners, parcel tracking APIs, or bubble wrap packaging:
- **Campus Drop Event Broadcast Beacon:** An in-app alert signals scheduled community drop hours (e.g., *Friday Lunch Break Drop @ 1:30 PM*).
- **Physical Campus Drop Zones:**
  1. *Canteen Amphitheatre & Lawn Steps* (Primary campus social hub)
  2. *Textile Department Lawn & Corridors* (Studio break swaps)
  3. *Resource Centre / Library Lobby* (Quiet indoor inspection spot)
- **Immediate In-Person Inspection:** Students inspect measurements and condition face-to-face before triggering the **"Received & Confirmed at Drop"** digital milestone.
